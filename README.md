# Urban-Heat-Island-Analyzer
This project focuses on spatial analysis using Python libraries like GeoPandas and Rasterio to simulate the analysis of Land Surface Temperature (LST) data to identify Urban Heat Islands (UHIs). Since actual GeoTIFF files are too large, the scripts will use NumPy to create mock raster data for demonstration. 
Theres no data folder , since this is for practice, but in the methodology file, you will find proper istruction.
